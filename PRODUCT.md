# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Reclutadores técnicos, líderes de ingeniería (Tech Leads / CTOs) y clientes directos que buscan el desarrollo integral de aplicaciones web y plataformas completas. Evalúan solidez técnica, capacidad de arquitectura de software, calidad de código y agilidad de entrega.

## Product Purpose
Exhibir la trayectoria profesional, capacidad de ingeniería y proyectos reales de Luis Guillermo Pérez Rubio. El objetivo de éxito es generar confianza inmediata y facilitar el contacto directo para oportunidades laborales y desarrollo de proyectos de software de alto impacto.

## Positioning
Ingeniero de Sistemas y Desarrollador Full-Stack versátil que combina una sólida base en ingeniería backend (arquitecturas modulares, modelado relacional riguroso en PostgreSQL/MySQL y tipado estricto con TypeScript/Java/PHP) con la destreza para construir interfaces de usuario rápidas, limpias y altamente optimizadas (Astro, Vue, React, Tailwind CSS, Next.js).

## Operating Context
Navegadores web modernos en escritorio y dispositivos móviles. Los visitantes navegan de forma ágil revisando el perfil general, explorando casos de estudio técnicos de proyectos, inspeccionando repositorios de código en GitHub y validando certificaciones oficiales.

## Capabilities and Constraints
- Rutas públicas: Inicio (`/`), Sobre mí (`/sobre-mi`), Proyectos (`/proyectos`), Detalle de Proyecto (`/proyectos/[slug]`), Contacto (`/contacto`).
- Arquitectura estática Zero-JS por defecto con Astro v7 + islas interactivas React (carrusel con zoom/touch y visor de certificados en modal).
- Transiciones fluidas entre páginas con Astro View Transitions.
- Sin dependencias de backend serverless para el renderizado del portafolio; todo el contenido se compila estáticamente a CDN global.
- Accesibilidad estricta con respeto a preferencias de reducción de movimiento (`prefers-reduced-motion`).

## Brand Commitments
- Nombre e Identidad: Luis Guillermo Pérez Rubio (`<LGPR/>`).
- Estética y Tono: Tipografía editorial contundente (Bebas Neue + Barlow), paleta monocromática estricta de alto contraste con acentos funcionales de estado (indicador de disponibilidad).
- Voz directa, profesional y técnica: fundamentada en decisiones de ingeniería, arquitecturas y resultados reales sin afirmaciones exageradas.

  - *Sistema de Gestión de Refugios*: Arquitectura modular en PHP + MySQL + SPA Vue 3.

  - *GomiFire*: PWA menú digital + sistema POS integrado con React 19 + Firebase Firestore.

## Product Principles
1. **Rigor sobre Decoración:** Cada elemento visual y de movimiento debe tener propósito (comunicar estado, jerarquía o continuidad).
2. **Claridad Arquitectónica:** Presentar los proyectos explicando el rol, las decisiones de arquitectura y la justificación técnica de la tecnología empleada.
3. **Rendimiento Innegociable:** Carga instantánea, Core Web Vitals impecables y accesibilidad en cualquier dispositivo sin fricción.
4. **Evidencia Tangible:** Todo proyecto presentado incluye enlaces a repositorios públicos de GitHub, sitios en producción o capturas de pantalla de interfaces reales.

## Accessibility & Inclusion
- Contraste tipográfico de alto contraste (WCAG AA/AAA).
- Navegación accesible por teclado en menús, botones y modales interactivos con tecla `Escape`.
- Respeto total de `prefers-reduced-motion` eliminando traslaciones espaciales complejas para usuarios sensibles.
